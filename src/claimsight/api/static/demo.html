ClaimSight

Auto-insurance claims triage: damage from photos, coverage from the policy text, fraud checks, a cost estimate, and an adjuster for anything the system isn't sure of. This demo runs in replay mode: every model output was recorded once, so nothing here calls a model, and filing a claim is free. Pick a sample, edit the statement if you like, and file it.
