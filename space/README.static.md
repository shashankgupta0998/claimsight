# ClaimSight demo

Auto-insurance claims triage: damage from photos, coverage from the policy text, fraud
checks, a cost estimate, and an adjuster (you) for anything the system isn't sure of.

This is a static page. ClaimSight runs in **replay mode**: every model output (detector,
embeddings, reranker, Claude's coverage reviews) was recorded once, so a claim always gets
the same answer. Each sample's answer, and both adjuster choices for the claims that wait
for one, were computed by the real API when this page was built and saved in `data/`.
Nothing here calls a model or a server.

Editing the statement needs the API: clone the repo and run `make demo`.

Source, evals and measured results: https://github.com/shashankgupta0998/claimsight
