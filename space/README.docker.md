# ClaimSight demo

Auto-insurance claims triage: damage from photos, coverage from the policy text, fraud
checks, a cost estimate, and an adjuster (you) for anything the system isn't sure of.

This Space runs the API in **replay mode**: every model output (detector, embeddings,
reranker, Claude's coverage reviews) was recorded once, so nothing here calls a model and
nothing is billed. Claims live in memory and disappear when the Space restarts.

- The page at `/` files the golden claims and their fraud variants.
- The API is at `/docs` (`POST /claims`, `GET /claims/{id}`, `POST /claims/{id}/review`).

Source, evals and measured results: https://github.com/shashankgupta0998/claimsight
